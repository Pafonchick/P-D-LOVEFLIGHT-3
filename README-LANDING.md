# Лендинг «Павел & Дарина»

Проект сделан без вложенных папок: все HTML, CSS, JavaScript и изображения лежат рядом. Номера Павла и Дарины уже добавлены в `script.js`.

## Где будут ответы гостей

Основное место — ваша Google Таблица, лист **«Ответы»**. Дополнительно ответы можно смотреть с телефона на странице `admin.html` и скачивать в CSV.

## Подключение ответов к Google Таблице

1. Создайте новую Google Таблицу, например **«Свадьба — ответы гостей»**.
2. В таблице откройте **Расширения → Apps Script**.
3. Удалите пример кода и вставьте содержимое файла `google-apps-script.gs`.
4. Сохраните проект.
5. В верхнем списке функций выберите `setupWeddingRsvp` и нажмите **Выполнить**.
6. Выдайте скрипту разрешения и придумайте секретный ключ длиной от 8 символов. Запишите его: он нужен только вам для `admin.html`.
7. Нажмите **Развернуть → Новое развёртывание → Веб-приложение**.
8. Выберите:
   - выполнять от имени: **вы**;
   - у кого есть доступ: **все пользователи**.
9. Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
10. URL текущего развёртывания уже добавлен в `GOOGLE_APPS_SCRIPT_URL` файла `script.js`:
   `https://script.google.com/macros/s/AKfycbxrdBYDNRBxB4--yMeXNeVxp-BcRBr71PUqkMjX9VgHtSFPsWvhQq9TZ9t7-9RAk3l88w/exec`.
11. Загрузите обновлённые файлы на GitHub Pages.

После этого каждый ответ автоматически появится в листе **«Ответы»**. Для просмотра через красивую страницу откройте `admin.html`, вставьте URL веб-приложения и секретный ключ. URL сохранится только в вашем браузере, ключ не сохраняется.

Пока URL не заполнен, форма сохраняет ответы только в браузере самого гостя. Это резервный режим, а не замена Google Таблицы.

## Что вам осталось сделать

1. В редакторе Apps Script убедитесь, что функция `setupWeddingRsvp` была запущена хотя бы один раз.
2. Запишите придуманный при настройке секретный ключ. Не добавляйте его в файлы сайта и не публикуйте на GitHub.
3. Распакуйте `pavel-darina-landing-github-ready.zip`.
4. Загрузите **содержимое** архива в корень GitHub-репозитория. Сам ZIP загружать на сайт не нужно.
5. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
6. После появления адреса сайта откройте его в режиме инкогнито и отправьте один тестовый ответ.
7. Проверьте, что строка появилась в Google Таблице на листе **«Ответы»**, затем удалите тестовую строку.
8. Для просмотра ответов с телефона откройте адрес сайта с `/admin.html` в конце. Вставьте URL Apps Script и секретный ключ, затем нажмите кнопку загрузки ответов.

Если вы измените код `google-apps-script.gs`, откройте **Развернуть → Управление развёртываниями**, нажмите значок редактирования, выберите **Новую версию** и снова нажмите **Развернуть**. При обновлении существующего развёртывания его URL обычно сохраняется.

## Публикация на GitHub Pages

1. Загрузите все файлы из этой папки в корень репозитория.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и каталог `/ (root)`.
5. После публикации GitHub покажет адрес сайта.
6. Этот адрес можно превратить в QR-код и вставить в печатные приглашения.

## Локальная проверка

Откройте терминал в папке проекта и выполните:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Основные файлы

- `index.html` — структура и текст;
- `styles.css` — дизайн, адаптивность и анимации;
- `final.css` — финальные адаптивные улучшения и сердечная загрузка;
- `script.js` — меню, таймер, слайдер и RSVP;
- `google-apps-script.gs` — обработчик Google Таблицы;
- `admin.html` и `admin.js` — закрытая страница просмотра ответов;
- изображения `.png` — фотографии и варианты билетов.
